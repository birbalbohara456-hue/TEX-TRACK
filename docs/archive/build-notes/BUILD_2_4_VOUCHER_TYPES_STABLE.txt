Implementation
--------------

  category and Tally name.
- F4 search, automatic form focus, list-row/scroll restoration and filtered-save
  restoration using the frozen KeyboardContextScope.
- Permanent Alt+D now opens the normal TexTrack dialog and returns the explicit
  protected-system message without database mutation.
- Database-derived system/custom enforcement prevents posted flag manipulation.
- Permanent canonical identity/system/base mapping remain immutable; the already
  exposed numbering and Tally configuration now persist.
- Custom display/Tally names remain editable with stable ID/canonical identity.

  custom type in the same transaction.
- No migration, CSS, global keyboard, voucher numbering allocation, JWO, Material
