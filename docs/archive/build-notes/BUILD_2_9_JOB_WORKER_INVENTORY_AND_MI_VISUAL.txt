IMPLEMENTED

11. Visible footer updated to Build 2.9.

ROOT CAUSES
- The earlier user-facing reports were separate projections rather than one production-control position.
- Old Material Received display could use aggregate labels; the consolidated report now projects MaterialInFinishedGoods.StockItem.Name for every persisted FG row.
- The T-format initially appeared stacked because Components/App.razor linked app.css but not the generated TexTrack.Web.styles.css bundle; Chrome computed display:block. Linking the generated bundle makes both halves render simultaneously.
- Closing Stock numeric selection could become stale after hierarchy changes; the new page selects and resolves stable RowKey DTOs.
- Nested Reports Esc was intercepted by the existing capture-phase menu handler, which always clicked the overlay. It now detects data-tt-parent, collapses one level and restores parent focus.
- The JWO Enter sequence in the authoritative base already uses the shared enabled/editable-control navigator. A real-Chrome regression now proves first Enter and second Enter without Tab or mouse; no page-level listener was added.
