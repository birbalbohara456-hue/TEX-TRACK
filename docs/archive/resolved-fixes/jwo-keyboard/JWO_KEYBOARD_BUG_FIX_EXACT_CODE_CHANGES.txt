FILE 1: Components/App.razor
================================================================================

LOCATION: Line 353 (in the global Enter key handler)
CHANGE TYPE: Add empty input validation check

BEFORE (BUGGY):
──────────────
351:                // Real ERP lookup: Enter selects the keyboard-highlighted match or first visible match.
352:                if (current.matches('[data-erp-lookup="true"]') && lookupButtons.length > 0) {
353:                    event.preventDefault();
354:                    event.stopPropagation();

AFTER (FIXED):
──────────────
351:                // Real ERP lookup: Enter selects the keyboard-highlighted match or first visible match.
352:                // But only if the input is not empty. Empty lookups should not auto-select.
353:                if (current.matches('[data-erp-lookup="true"]') && lookupButtons.length > 0 && current.value.trim() !== '') {
354:                    event.preventDefault();
355:                    event.stopPropagation();

EXPLANATION:
The condition now requires THREE things to be true before auto-selecting a lookup:
1. current.matches('[data-erp-lookup="true"]')  - Field is marked as lookup
2. lookupButtons.length > 0                     - Lookup has visible options
3. current.value.trim() !== ''                  - Input is NOT empty (NEW)

When the input IS empty, this condition fails and execution falls through to
the data-enter-empty-action handler (lines 340-349), which triggers the close.
