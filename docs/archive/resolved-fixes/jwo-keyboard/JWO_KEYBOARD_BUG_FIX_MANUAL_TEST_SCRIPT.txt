WHAT WAS FIXED
================================================================================

BUG DESCRIPTION:
When pressing Enter on a BLANK Component Stock Item field in the Job Work Out 
Order's Component Allocation window, the system would automatically select and 
capture the FIRST lookup result instead of closing the allocation window. This 
prevented users from skipping blank component rows or exiting the allocation.

EXACT SYMPTOM:
User Flow ERROR:
1. Open Job Work Out Order → Component Allocation
2. Leave Component Stock Item field empty
3. Press Enter
4. BUG: First stock item auto-selected (should close window instead)

ROOT CAUSE:
App.razor line 355-358: Global Enter handler for lookup fields checked for 
lookup results but did NOT check if the input field was empty before 
auto-selecting the first result.

================================================================================
SOLUTION IMPLEMENTED
================================================================================

Three-part fix with backward-compatible design:

PART 1: App.razor (Global Enter Handler)
└─ Line 353: Added && current.value.trim() !== '' 
   Effect: Lookup auto-selection now SKIPPED when input is empty
   Benefit: Allows data-enter-empty-action to trigger instead

PART 2: JobWorkOutOrder.razor (Component Stock Item Input)
└─ Line 365: Added data-enter-empty-action="jwo-component-empty-action-..."
   Effect: When empty + Enter, the empty-action button is triggered
   Benefit: Routes empty Enter to CloseComponentAllocation() instead of lookup

PART 3: JobWorkOutOrder.razor (New Hidden Buttons)
├─ Lines 413-418: jwo-component-empty-action
│  └─ Calls: CloseComponentAllocation()
│     Triggered: When Component Stock Item is empty + Enter
│
├─ Lines 419-424: jwo-component-qty-focus  
│  └─ Calls: FocusComponentQuantity()
│     Triggered: When Component Godown field + Enter
│     Benefit: Enables Godown → Quantity keyboard navigation
│
└─ Lines 1252-1267: FocusComponentQuantity() method
   └─ Validates: Godown is selected
	  Sets focus to: Required Quantity field
